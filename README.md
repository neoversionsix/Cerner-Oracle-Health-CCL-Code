# Cerner-Oracle-Health-CCL-Code

Welcome to my repository for Cerner Command Language (CCL) code. 

## Disclaimer and License
This code is free for anyone to use, but you do so entirely at your own risk. Please ensure you test any code thoroughly in a non-production environment before utilizing it in production.

## Data Privacy
The code in this repository has been meticulously checked and does not contain any sensitive data, Protected Health Information (PHI), or confidential institutional information. I maintain a larger private repository of code, but due to time constraints, I have only migrated a subset of that code to this public repository.

## Repository Structure

### `DATA EXTRACTION/`
This folder contains code for data extraction, including both queries and programs. The programs here are effectively temporary in nature—they just need to be saved and built in your environment before running.

### `mpages/`
This folder is dedicated to code used for building and customizing MPages.

### `dyndoc/`
This folder contains code for building programs designed to pull specific information into Dynamic Documentation (DynDoc) templates.
